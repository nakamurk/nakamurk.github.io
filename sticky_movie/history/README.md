# sticky_movie

YouTube動画の任意区間にコメントを付け、同じ区間を再生しながら振り返るためのレビュー支援ツールです。

- YouTube IFrame API を利用
- 区間コメントを JSON / Markdown で保存・復元
- ブラウザキャッシュでリロード(F5)後も入力内容を自動復元

## 正式版

- `v1.0.0/` を正式版フォルダとして追加
- 実装ベースは `beta_v1.5`（現行機能を反映）

## 使い方（v1.0.0）

1. `v1.0.0/index.html` を開く。
2. ヘッダーの `動画を読み込む` で YouTube ID/URL を読み込む。
3. コメント入力で分類・種類・事象・コメントを入力し、`コメント追加` を押す。
4. コメント一覧の `再生` で該当区間を再生する。
5. 必要に応じてフィルター（分類 / 種類 / 事象 / コメント）で絞り込む。
6. `フィルターリセット` で一覧フィルターを初期状態へ戻す。
7. `MD読込` / `MD保存` でレポートを入出力する。

## キーボード操作（YouTube標準）

画面内の Usage に記載の通り、YouTubeプレーヤーの代表的なショートカットが使えます。

- Space / K: 再生・一時停止
- J / L: 10秒戻る・進む
- ← / →: 5秒戻る・進む
- ↑ / ↓: 音量調整
- F: 全画面
- M: ミュート切替
- 0〜9: 動画位置ジャンプ

## JSON 形式

保存データは次の形式です。

```json
{
  "video_id": "YouTubeの動画ID",
  "comments": {
    "0": {
      "seek": "12.3",
      "sleep": "8",
      "comment": "この部分を確認"
    },
    "1": {
      "seek": "42",
      "sleep": "5",
      "comment": "ここも要チェック"
    }
  }
}
```

## 主な現行仕様（v1.0.0）

- コメント一覧の開始秒数ヘッダークリックで昇順/降順ソート
- 種類フィルターはプルダウン選択
- コメント一覧の種類セルもプルダウン編集
- 再生時はページ最上部へスクロール
- `全体レポート` は `page-header` の下から表示

## バージョン差分

### beta_v1.0

- クエリ文字列（`video_id`, `comments`）で初期データを反映
- JSON読込時は動画IDが異なる場合に別URLへ遷移
- コメント表は静的な `<table>` を直接利用

### beta_v1.1

- コメント表を `resetTable()` で動的再生成する方式に変更
- `videoId` 入力変更時に `cueVideoById` で動画を差し替え
- JSON読込時に表を初期化してからコメント行を再構築
- `backVideo()`（指定秒数分戻る）を追加

### beta_v1.2

- バージョン表記を `beta_v1.2` に統一
- 再生停止タイマーを `videoTimer` に整理し、連続再生時の停止制御を安定化

### beta_v1.3

- `videoId` を変更した際、コメント表を自動リセット
- `pauseVideo()` 実行時に `sleepTime` を 0 へ戻し、意図しない再停止を防止
- 再生対象動画の切替時に状態をより明確に初期化

### beta_v1.4

- ローカルJSON読込を再設計し、JSON形式チェックとエラーハンドリングを追加
- YouTube動画ID/URLの正規化読込（`youtu.be` / `youtube.com/watch` / `embed`）に対応
- 「動画を読み込む」ボタンとステータス表示を追加
- プレーヤー未準備時の保留読込や、行削除後のJSON保存整合性を改善

### beta_v1.5

- 上段を ①コーチングレポート起動ボタン（約5%）/ ②動画領域（約50%）/ ③コメント入力（約45%）に再配置
- 下段に ④コメント一覧を 100% 幅で配置
- コーチングレポートは左トグルボタンから開く 70% 幅オーバーレイ表示へ変更
- 動画設定は「設定」トグル内に集約し、ID/URL と再生秒数入力に限定
- JSON読込/保存とMarkdown読込/生成/保存を1セクションへ統合
- コメント分類をホバー付きトグルUI（前半・後半・その他）へ変更
- コメント追加時に前半/後半/その他メモへ自動連携し、各メモから動画再生可能
- 動画エリアとレポート全体をブラウザ幅ベースでレスポンシブ化
- Markdown書き出しに「記録ソース（ファイルパスまたはURL）」を出力
- Markdown読込時に、コーチングレポート各項目、コメント一覧、前半/後半/その他メモ、記録ソースを復元
- Markdown内の記録ソースが YouTube URL/動画ID の場合は、動画ID欄とプレーヤー読込も更新
- セクション表示をトグル化し、画面下部の前半メモ/後半メモ/その他メモ表示は廃止
- Markdown保存ファイル名はレポートタイトルをもとに安全な文字へ整形して生成
- メンテナンス性向上のため、HTML / CSS / JavaScript を分離

### v1.0.0

- `beta_v1.5` をベースに正式版フォルダを追加
- `動画を戻す` ボタンを削除
- ヘッダーに `MD読込` / `MD保存` を配置
- コメント一覧のフィルターに `種類プルダウン` と `リセット` を追加
- コメント一覧の `種類` をプルダウン編集に変更
- レポート表示位置を `page-header` 下端基準へ調整

## メモ

- 単体HTMLとして動く実装です（ビルド工程なし）。
- `v1.0` のURLは `http://<host>/sticky_movie/v1.0/index.html` を前提とした記述があり、現在のフォルダ名（`beta_v1.0`）と差異があります。
  - 現在の構成で利用する場合は、`beta_v1.0` 側のURL生成ロジックの見直しを推奨します。

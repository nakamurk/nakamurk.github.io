# sticky_movie ユーザーガイド

sticky_movie は、YouTube 動画の気になる場面に時刻付きコメントを付けて、振り返りレポートを作るためのツールです。

## 1. すぐに使う

1. ブラウザで `v1.0.0/index.html` を開く
2. `動画を読み込む` に YouTube の URL または動画 ID を入力して読み込む
3. コメント欄に内容を入力して `コメント追加` を押す
4. コメント一覧の `再生` で該当区間を確認する

## 2. 基本操作

### 動画
- YouTube URL / 動画 ID のどちらでも読み込みできます
- `設定` の中で再生秒数を指定できます

### コメント
- 分類（前半 / 後半 / その他）を選べます
- `事象` / `種類` / `コメント` を入力して保存できます
- 一覧から個別に再生・削除できます

### 絞り込み
- 分類 / 種類 / 事象 / コメントで絞り込みできます
- `フィルターリセット` で初期状態に戻せます

### レポート
- `全体レポート` でコーチングレポートを表示できます
- `MD読込` / `MD保存` で Markdown ファイルの入出力ができます

## 3. 保存と復元

- 入力内容はブラウザに自動保存され、リロード後に復元されます
- JSON 形式でコメントを保存・読込できます
- Markdown 形式でレポートを保存・読込できます

## 4. つまずいたとき

- 動画が再生されない
  - YouTube の URL または動画 ID が正しいか確認してください
  - ネットワーク接続を確認してください

- 読込に失敗する
  - JSON / Markdown の形式が壊れていないか確認してください

- 入力内容が消えた
  - 同じブラウザ・同じ端末で開いているか確認してください
  - プライベートブラウズでは自動保存が無効になる場合があります

## 5. 推奨環境

- 最新版の Chrome / Edge / Firefox / Safari
- JavaScript と localStorage が有効なブラウザ

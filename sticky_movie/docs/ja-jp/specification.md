# sticky_movie 仕様書

## 概要
sticky_movie は、YouTube動画の任意区間にコメントを付与し、コーチングレポートを生成するブラウザベースのツールです。

## スコープ
- 対象バージョン: v1.0.0（正式版）
- 実行形態: 単一ページWebアプリ（ビルド工程なし）
- 主な利用目的: レフリー/コーチングのレビュー業務

## 機能仕様
0. 画面レイアウト
- `page-header` 配下に動画エリアとコメント入力パネルを配置すること。
- 下段はコメント一覧を100%幅で表示すること。
- コーチングレポートはトグル操作で開く左側 70% 幅のオーバーレイで表示すること。
- コーチングレポート表示開始位置は `page-header` の下端基準とすること。

1. 動画読み込み
- YouTube動画IDまたはURLの入力を受け付ける。
- URL形式を正規化し、YouTube IFrame API経由で読み込む。
- 手動読み込みトリガーに対応する。
- 「設定」トグルには動画ID/URLと再生秒数の入力のみを配置する。

2. コメント付与
- 以下を持つコメント行を追加できること:
  - 開始時刻（seek）
  - 再生秒数（sleep）
  - コメント本文
  - 分類（前半 / 後半 / その他）
  - 事象
  - 種類
- 行ごとに区間再生できること。
- 行を削除できること。
- コメント一覧の種類セルはプルダウンで編集できること。

3. データ入出力
- JSONの読み込み/保存に対応すること。
- Markdownの読み込み/生成/保存に対応すること。
- ブラウザ localStorage で自動キャッシュ保存/復元に対応すること。

4.5 コメント一覧フィルター
- 分類/種類/事象/コメントで絞り込みできること。
- 種類フィルターはプルダウンで選択できること。
- フィルターリセット操作を提供すること。

4. コーチングレポート
- レポートメタデータを保持すること:
  - タイトル、KO、会場、天候、レフリー、コーチ、記録ソース
- 箇条書きセクションを保持すること:
  - サマリ、レギュレーション、事前課題ヒアリング、良かった点、
  - 本人のコメント、直接伝達済み、未伝達、その他
- Markdownレポートを出力できること。

5. Markdown読込時の挙動
- Markdownの各セクションを解析し、レポート項目を復元すること。
- 可能な範囲でメモセクションからコメント行を復元すること。
- Markdown内容に基づいて箇条書き項目を更新すること。
- 記録ソースがYouTube URL/IDの場合、動画欄を更新しプレーヤー読み込み対象に反映すること。

6. 箇条書き欄への読込データ反映
- 読込データは以下のUIフィールドへ対応付けて反映すること:
  - reportSummary（サマリ）
  - reportRegulation（レギュレーション）
  - reportPreInterview（事前課題ヒアリング）
  - reportGoodPoints（良かった点）
  - reportSelfComment（本人のコメント）
  - reportShared（直接伝達済み）
  - reportUnshared（未伝達）
  - reportOther（その他）
- Markdown読込時は、見出しと箇条書き行を解析して上記フィールドへ反映すること。
- JSON読込時は、`report_bullets` オブジェクトが存在する場合に上記フィールドへ反映すること。

## 非機能仕様
- デスクトップ/モバイルに対応したレスポンシブレイアウトであること。
- バックエンド依存を持たないこと。
- エラーメッセージをステータス領域に表示すること。

## 制約
- JavaScript有効なブラウザ環境が必要。
- YouTube再生はIFrame APIの可用性とorigin制約に依存する。

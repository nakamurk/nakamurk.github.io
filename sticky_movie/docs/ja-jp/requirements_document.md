# sticky_movie 要件定義書

対象バージョン: v1.0.0（正式版）

## 1. 目的
YouTube試合映像のレビューにおいて、時刻付きコメント管理とコーチングレポート作成を軽量に行えるツールを提供する。

## 2. ステークホルダー
- コーチ / レビュアー
- レフリー（レポート対象）
- 静的サイトリポジトリ管理者

## 3. 機能要件
1. 動画要件
- FR-001: システムはYouTube ID/URL入力を受け付けること。
- FR-002: システムは選択動画を埋め込みプレーヤーへ読み込むこと。
- FR-003: システムは動画設定UIを「設定」トグルに集約し、動画ID/URLと再生秒数のみ入力可能とすること。

2. コメント要件
- FR-101: システムは開始時刻と再生秒数を持つコメント行を作成できること。
- FR-102: システムは分類選択（前半、後半、その他）を提供すること。
- FR-103: システムはコメント/事象/種類テキストを編集できること。
- FR-104: システムは行設定に基づき動画区間を再生・停止できること。
- FR-105: システムはコメント行を削除できること。

3. データ入出力要件
- FR-201: システムはコメントをJSONとして書き出せること。
- FR-202: システムはJSONを読み込みコメントを再構築できること。
- FR-203: システムはMarkdown形式のコーチングレポートを生成できること。
- FR-204: システムはMarkdownを読み込みレポートデータを復元できること。
- FR-205: システムはMarkdownをダウンロード可能ファイルとして保存できること。

4. レポート要件
- FR-301: システムはレポートのメタデータ項目を保持できること。
- FR-302: システムはコーチング内容の箇条書き項目を保持できること。
- FR-303: システムはMarkdown読込時に箇条書き項目を更新できること。
- FR-304: システムは読込データ（MarkdownまたはJSON）を箇条書き入力欄
	（reportSummary, reportRegulation, reportPreInterview, reportGoodPoints,
	reportSelfComment, reportShared, reportUnshared, reportOther）へ対応付けて反映できること。
- FR-305: システムはコーチングレポートを左側70%幅オーバーレイとして表示できること。
- FR-306: システムは「全体レポート」押下時、`page-header` の下端位置からレポートを表示すること。

6. 画面レイアウト要件
- FR-501: システムは `page-header` の下に、動画領域とコメント入力領域を横並び表示すること。
- FR-502: システムはコメント一覧をそれらの下段に100%幅で表示すること。

5. ローカル保存要件
- FR-401: システムはフォーム更新内容をローカルキャッシュへ自動保存すること。
- FR-402: システムはページ初期化時にキャッシュ復元を試行すること。
- FR-403: システムはリロード（F5）後も可能な範囲で編集内容を維持すること。

7. フィルター要件
- FR-601: システムは分類/種類/事象/コメントによる絞り込みを提供すること。
- FR-602: システムは種類フィルターをプルダウンとして提供すること。
- FR-603: システムはフィルターリセット操作を提供すること。

## 4. 非機能要件
- NFR-001: アプリはビルドツールなしで静的ファイルとして動作すること。
- NFR-002: アプリはデスクトップ/モバイル幅で利用可能であること。
- NFR-003: アプリは失敗時にユーザー向けステータスメッセージを表示すること。
- NFR-004: アプリは可能な範囲でリロード時のデータ損失を回避すること（キャッシュ）。

## 5. 前提条件と制約
- AC-001: ユーザーはYouTubeリソースへアクセス可能なネットワークを持つこと。
- AC-002: ブラウザはモダンJavaScriptとlocalStorageをサポートすること。
- AC-003: 配置先は静的ホスティングであること。

## 6. 対象外
- 認証およびユーザーアカウント。
- サーバーサイド保存と同期。
- 複数ユーザー同時コラボレーション。
